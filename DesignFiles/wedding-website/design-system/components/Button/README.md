# Button

Square, uppercase actions with wide tracking. Use `a.wd-btn` for links to pages, maps and timetables.

**Variants:**
- `wd-btn--primary` (`accent` fill, `on-accent` text): the one main action on a page, such as See the schedule.
- `wd-btn--outline` (`line-strong` edge): secondary actions, such as Add to calendar.
- `wd-btn--link` (underlined text): inline or tertiary actions, such as Ferry timetable.
- `wd-btn--on-forest` (`lace` fill, `forest` text): any action on a `forest` band, including the hero.

**You provide:** a label of one to three words, written in sentence case (CSS uppercases it).

- One primary button per screen.
- No icons or rounded corners.
