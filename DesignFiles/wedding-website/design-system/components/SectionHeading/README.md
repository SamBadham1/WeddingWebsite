# SectionHeading

The opening of every section: an uppercase eyebrow, a script title and a hairline rule with a small diamond, all centred.

**Markup:** `div.wd-heading` > `p.wd-heading__eyebrow` + `h2.wd-heading__title` + `div.wd-heading__rule[aria-hidden]` > `span`.

**You provide:** a short eyebrow (two to four words) and a title (one to three words, title case).

- On a `forest` band, add `wd-heading--on-forest`: the title turns `lace` and the eyebrow and rule turn `sage`.
- Never set an all-caps word or abbreviation (FAQ) as the script title. Put it in the eyebrow and write the title out ("Questions").
- The title is 44px under 600px wide.
